# כוכב הנחיל (StarCraft Gamebook)

ספר משחק בעברית ביקום סטארקראפט. אפליקציית עמוד יחיד, mobile-first, עם `dir="rtl"` מלא.

## הרצה

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה לפרודקשן
npm run lint
```

## מה יש כאן

- בחירת דמות: טראן, זרג או פרוטוס. לכל גזע מדדי פתיחה ופריטים משלו.
- הטלת קוביה: בדיקות מזל וקרב (d6 / d20) משובצות בתוך הבחירות. הנוסחה היא הטלה ועוד המדד הרלוונטי מול סף ההצלחה, והתוצאה קובעת לאיזה צומת ממשיכים.
- מדדים ומלאי: שורת מצב עליונה שנפתחת ונסגרת בלחיצה. כל מדד מוצג עם הסבר מה הוא עושה, וכל פריט עם הסבר למה הוא שימושי. פריט שמשמש כתנאי לבחירה כלשהי בעלילה מסומן כ"מפתח", והסימון מחושב מהגרף עצמו ולא נכתב ידנית.
- שקיפות של הבדיקות: בחירה עם קוביה מציגה מראש את סוג הקוביה, המדד שנכנס לחישוב, סף ההצלחה וסיכוי ההצלחה באחוזים.
- מסך "איך משחקים" עם כללי הקוביה, המדדים, המלאי והבחירות הנעולות, ומונחון סטארקראפט מלא.
- מונחי סטארקראפט בטקסט מקושרים לוויקי ונפתחים בלשונית חדשה, בהופעה הראשונה של כל מונח בעמוד.
- המשכת משחק: השמירה נכתבת ל-localStorage בכל מעבר עמוד. בפתיחה הבאה מוצג מסך המשכה עם הגזע, שם העמוד, מתי שיחקת לאחרונה וכמה עמודים קראת.
- קוד שמירה נייד: המצב כולו מקודד ל-base64 להעתקה, כדי להמשיך את אותו משחק בדפדפן או במכשיר אחר. הקוד נטען חזרה מאותו חלון.
- חזרה עמוד אחורה לפי מסלול הקריאה. הפריטים והמדדים שנצברו נשארים, כי המסלול הוא ניווט ולא ביטול.

## מבנה

```
src/
  types.ts              טיפוסי הגרף והמצב
  data/races.ts         הגזעים, המדדים ותוויותיהם
  data/story/
    terran/ zerg/ protoss/   act1..act4 לכל גזע, ו-index שמאחד אותם
    index.ts                 בניית הגרף ובדיקת מזהים כפולים
  engine/dice.ts        הטלות ובדיקות
  engine/rules.ts       תנאי בחירה והחלת אפקטים
  engine/gameState.ts   reducer, מסלול חזרה, שמירה וטעינה
  engine/saveCode.ts    קידוד ופענוח של קוד שמירה נייד
  data/glossary.ts      מונחי סטארקראפט, קישורי ויקי וזיהוי המונחים בטקסט
  data/items.ts         הסבר לכל פריט, וחישוב הפריטים שמשמשים כתנאי
  ui/                   מסכים: המשכה, בחירת דמות, עלילה, שורת מצב, קוביה, קוד שמירה, עזרה
```

## הוספת תוכן

צומת הוא אובייקט אחד:

```ts
{
  id: 'ter_backwater',
  title: 'תחנת בקוואטר',
  text: ['פסקה', 'פסקה'],
  effects: { addItems: ['דגימת רקמה זרה'], stats: { tactics: 1 }, addFlags: ['saw_creep'] },
  choices: [
    { text: 'המשך פנימה', to: 'ter_survivors' },
    { text: 'זמין רק עם הרסיס', to: 'ter_end_truth', requires: { item: 'רסיס נשק זרגי' } },
    {
      text: 'פרוץ פנימה',
      check: { dice: 6, stat: 'tactics', target: 7, label: 'בדיקת מזל',
               successNodeId: 'ter_survivors', failureNodeId: 'ter_ambush' },
    },
  ],
}
```

מוסיפים אותו לקובץ המערכה המתאים תחת `src/data/story/<race>/`. מערכה חדשה היא קובץ חדש שמשורשר ב-`index.ts` של אותו גזע, ומסלול חדש משורשר ב-`src/data/story/index.ts`, שגם זורק שגיאה על מזהה כפול. אפקטים של צומת מוחלים רק בביקור הראשון, כך שחזרה לצומת לא מכפילה פריטים או מדדים.

`requires` תומך ב-`item`, `race`, `flag`, `notFlag` ו-`minStat`. בחירה שתנאיה לא מתקיימים מוצגת נעולה עם הסבר בעברית, במקום להיעלם מהמסך.

## סטטוס

150 צמתים, 50 לכל גזע, ב-22 סיומים. כל גזע מחולק לארבע מערכות:

- טראן: מאר סארה, בני קורהאל ואנטיגה פריים, נפילת טרסוניס, והפשיטה על צ׳אר.
- זרג: ההדבקה הראשונה, המצוד על קרייגן, לידת מלכת הלהבים והפלישה לאייר.
- פרוטוס: הטיהור של צ׳או סארה, הגלות, הקרב על אייר, והצלילה אל המעטפת.

כל היעדים בגרף נבדקו כקיימים וישיגים מצומת הפתיחה, בלי מזהים כפולים ובלי צמתים ללא המשך.
